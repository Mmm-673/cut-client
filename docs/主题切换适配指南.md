# 主题切换适配指南

## 🎯 问题说明

当前主题切换功能已实现，但只有 TabBar 样式发生了变化，页面内容没有变化。这是因为在小程序中，我们需要给每个页面的根元素添加主题类名。

4. `subpkg/mine/setting.vue` - 设置页面

## 📝 如何适配其他页面

### 步骤 1：在 script setup 中添加主题逻辑

在每个需要适配主题的页面中，找到 `<script setup>` 部分，添加以下代码：

```javascript
// 在 import 部分添加
import { useThemeStore } from '@/store'

// 在组件逻辑部分添加
const themeStore = useThemeStore()
const themeClass = computed(() => `theme-${themeStore.theme}`)
```

完整示例：

```javascript
<script setup>
import { ref, computed } from 'vue'
import { useThemeStore } from '@/store'  // 添加这行

const themeStore = useThemeStore()  // 添加这行
const themeClass = computed(() => `theme-${themeStore.theme}`)  // 添加这行

// 其他原有代码...
</script>
```

### 步骤 2：在模板根元素添加主题类

找到页面模板的根元素（通常是第一个 `<view>` 标签），添加 `:class="themeClass"` 属性。

**修改前：**
```vue
<template>
  <view class="page-wrapper">
    <!-- 页面内容 -->
  </view>
</template>
```

**修改后：**
```vue
<template>
  <view class="page-wrapper" :class="themeClass">
    <!-- 页面内容 -->
  </view>
</template>
```

## 🎨 如何验证主题切换

1. 打开应用
2. 进入"我的"页面
3. 点击右上角"设置"
4. 切换主题开关
5. 观察页面颜色是否变化：
   - 深色主题：深色背景，浅色文字
   - 浅色主题：浅色背景，深色文字

## 🔧 技术原理

### CSS 变量定义

主题颜色在 `static/scss/themes.scss` 中定义：

```scss
// 默认深色主题
page {
  --bg-page: #121619;
  --bg-card: #1E252B;
  --text-primary: #ffffff;
  --text-secondary: #9CA3AF;
  /* ... 更多变量 */
}

// 浅色主题覆盖
.theme-light {
  --bg-page: #F5F7FA;
  --bg-card: #FFFFFF;
  --text-primary: #1F2937;
  --text-secondary: #6B7280;
  /* ... 更多变量 */
}
```

### 主题类名机制

当给页面根元素添加 `theme-light` 类名后，该元素及其子元素都会使用浅色主题的 CSS 变量。

### 页面样式适配

所有页面都已经使用 CSS 变量替代了硬编码颜色，例如：

```scss
// 修改前
background-color: #121619;
color: #ffffff;

// 修改后
background-color: var(--bg-page);
color: var(--text-primary);
```

## 💡 快速批量适配技巧

如果你想快速适配所有页面，可以使用以下步骤：

1. 在编辑器中使用"在文件中查找"功能
2. 查找 `<script setup>`，添加主题导入和逻辑
3. 查找模板根元素 `<view class="`, 添加 `:class="themeClass"`

## ❓ 常见问题

### Q: 切换主题后页面没有变化怎么办？

A: 请检查：
1. 页面根元素是否添加了 `:class="themeClass"`
2. script setup 中是否正确添加了主题逻辑
3. 页面样式是否使用了 CSS 变量（var(--...)）

### Q: 部分元素颜色没有变化怎么办？

A: 检查该元素的样式是否还在使用硬编码颜色，需要替换为 CSS 变量。

### Q: 小程序和 H5 表现不一致怎么办？

A: 两个平台都使用相同的 CSS 变量方案，表现应该一致。如果有问题，请检查条件编译的代码块。

## 📞 需要帮助？

如果在适配过程中遇到问题，请检查：
1. 浏览器/开发者工具的控制台是否有错误
2. 元素审查中是否能看到 CSS 变量被正确应用
3. 主题类名是否被正确添加到根元素
