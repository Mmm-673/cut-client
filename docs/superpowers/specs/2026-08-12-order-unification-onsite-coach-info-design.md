# 订单融合与现场订单助教信息展示 设计文档

## 背景

本次需求包含两个独立但相关的改动：
1. 现场订单详情页新增助教信息展示（头像、艺名），接口已适配 `coach` 字段
2. 普通订单与现场订单列表融合，统一通过 `getOrderList` 查询，新增 `type` 字段区分，删除独立的现场订单入口

## 目标

- 用户在订单列表中可以同时看到普通订单和现场订单，通过类型标签区分
- 点击不同类型的订单跳转到对应的详情页
- 现场订单详情页展示助教头像和艺名，可点击跳转到助教详情页
- 移除"我的"页面的现场订单独立入口和独立的现场订单列表页

---

## 一、API 层调整

### 1.1 订单列表接口

- **文件**：`api/billiard/order.js`
- **接口**：`getOrderList`（`GET /app-api/billiard/order/page`）
- **变更**：后端已融合，返回列表项新增 `type` 字段
  - `type: 1` — 普通订单
  - `type: 2` — 现场订单
- **前端改动**：无需改动接口定义，直接使用返回的 `type` 字段即可

### 1.2 现场订单详情接口

- **文件**：`api/billiard/onsiteOrder.js`
- **接口**：`getOnsiteOrderDetail`（`GET /app-api/billiard/onsite-order/get`）
- **变更**：响应新增 `coach` 对象字段
  - `coach.id` — 助教 ID
  - `coach.stageName` — 助教艺名（可为 null）
  - `coach.avatar` — 助教头像 URL（可为 null）
  - `coach` 整体可为 null（助教资料不存在时）
- **前端改动**：无需改动接口定义，直接使用返回的 `coach` 字段即可

## 二、订单列表页改造（pages/order/list.vue）

### 2.1 卡片新增类型标签

- **位置**：服务类型图标 + 名称的右侧
- **样式**：小尺寸圆角标签，文字小号
  - 普通订单：绿色系（主题色 `#00BB88` / `#00d4aa`），文字"普通订单"
  - 现场订单：橙色系（`#f5a623` / `#F59E0B`），文字"现场订单"
- **主题适配**：深色/浅色主题下颜色需要适配，使用 CSS 变量或条件 class

### 2.2 卡片字段条件渲染

由于两种订单的字段有差异，卡片中部分内容需要按 `type` 条件渲染：

| 区域 | 普通订单 (type=1) | 现场订单 (type=2) |
|------|-------------------|-------------------|
| 时间行 | "预约时间" + 预约时间 | "开始时间" + 开始时间 |
| 地点/时长行 | "服务地点" + 球厅地址 | "服务时长" + 时长 |
| ID 字段 | `orderId` | `id` |
| 裁教/助教 | "裁教" + 姓名 | "助教" + 姓名 |

### 2.3 点击跳转逻辑

点击订单卡片时，根据 `type` 字段分流：

```javascript
const goToDetail = (order) => {
  if (order.type === 2) {
    uni.navigateTo({ url: `/subpkg/onsite/detail?id=${order.id}` })
  } else {
    uni.navigateTo({ url: `/subpkg/order/detail?id=${order.orderId}` })
  }
}
```

### 2.4 操作按钮条件渲染

底部操作按钮根据订单类型和状态分别渲染：
- 普通订单：取消订单、去评价、再约一次、加钟 等
- 现场订单：去支付、去评价 等
- 保持现有各自的按钮逻辑不变，用 `v-if="order.type === 1/2"` 区分

### 2.5 Tab 筛选

保持现有 8 个 Tab（全部、待付款、待接单、已接单、进行中、待评价、已完成、已取消）不变。
两种类型的订单按状态值归入对应 Tab，混合展示。

## 四、现场订单详情页改造（subpkg/onsite/detail.vue）

### 4.1 新增助教信息卡片

- **位置**：服务信息卡片之后，订单信息卡片之前
- **内容**：
  - 左侧：助教头像（圆形，尺寸与普通订单详情页裁教头像一致）
  - 右侧：助教艺名（主标题） + 助教 ID（副标题，小字）
  - 卡片标题："助教信息"

### 4.2 点击跳转

- 点击整个助教信息卡片，跳转到助教详情页
- 跳转路径：`/subpkg/coach/detail?id=${coach.id}`
- 与普通订单详情页的裁教卡片跳转行为一致

### 4.3 空值处理

- `coach` 为 `null` 时，不渲染助教信息卡片
- `coach.avatar` 为 `null` 或空时，显示默认头像（使用项目现有的默认头像资源）
- `coach.stageName` 为 `null` 或空时，显示"未知助教"

### 4.4 新增计费规则提示卡片

- **位置**：服务信息卡片之后，助教信息卡片之前（如果有助教卡片的话）
- **样式**：浅背景色小卡片，带信息图标，文字为提示文案
- **数据来源**：根据订单的服务类型 + 起步时长动态生成提示文案
- **提示文案映射表**：

| 类型值 | 服务名称 | 起步时长 | 提示文案 |
|--------|----------|----------|----------|
| 1 | 台球指导 | 1小时 | "温馨提示：台球指导起步时长为1小时，不足1小时按1小时计费，超出部分按分钟计费。" |
| 2 | 潮玩领航 | 2小时 | "温馨提示：潮玩领航起步时长为2小时，不足2小时按2小时计费，超出部分按分钟计费。" |
| 3 | 酒艺品鉴 | 4小时 | "温馨提示：酒艺品鉴起步时长为4小时，不足4小时按4小时计费，超出部分按分钟计费。" |
| 4 | 影视赏析 | 8小时 | "温馨提示：影视赏析起步时长为8小时，不足8小时按8小时计费，超出部分按分钟计费。" |

- **实现方式**：
  - 在 `subpkg/onsite/detail.vue` 中定义计费规则映射常量（`BILLING_RULES`），以服务类型数值（1/2/3/4）为 key
  - 根据订单详情中的服务类型字段（如 `serviceType`）匹配对应文案
  - 如果匹配不到已知服务类型，则不展示该提示卡片
- **主题适配**：卡片背景色和文字颜色适配深色/浅色主题
